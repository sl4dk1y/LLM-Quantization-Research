# Научная статья

Рукопись ещё не создавалась. Планируется статья на русском языке с рабочим названием «Экспериментальное исследование влияния квантования на качество и ресурсную эффективность локальных языковых моделей». Структура и оформление будут определены после выбора журнала и проверки его актуальных требований. Предварительные гипотезы не должны излагаться как установленные выводы.
