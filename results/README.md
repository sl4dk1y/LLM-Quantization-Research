# Результаты

Эмпирических результатов пока нет. В будущем исходные измерения будут сохраняться без перезаписи, а производные таблицы и графики — сопровождаться способом расчёта и ссылкой на исходные данные. Крупные и потенциально ограниченные лицензией артефакты не включаются в репозиторий автоматически.
