# Эксперименты

Эксперименты пока не проводились. Здесь позднее будут храниться утверждённые протоколы, конфигурации и воспроизводимые команды запуска. Для каждого запуска следует фиксировать версии и контрольные суммы весов, данные, параметры вывода, состояние оборудования и причины исключения. Изменения протокола оформляются явно до следующих запусков.
