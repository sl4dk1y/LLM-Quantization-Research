# Совместная разработка

В проекте два участника и один общий стенд. Первый отвечает за общую архитектуру, Apple Metal/macOS, методологию и общие компоненты. Второй собирает сведения своего компьютера и реализует NVIDIA CUDA-адаптер, метрики и платформенные safety thresholds. Оба согласуют матрицу, воспроизводимость, интеграцию и анализ.

Порядок работы: владелец проверяет общие контракты и документацию; второй участник собирает hardware manifest; участники согласуют capabilities и профиль; каждый самостоятельно подготавливает свою платформенную ветку; изменения общих интерфейсов проходят отдельное согласование; интеграция идёт через review. Текущая задача не выполняла Git-операций.

Общие `runner`, `scorer`, форматы JSONL и научные ключи не должны расходиться между реализациями. Парные сравнения используют общий logical observation key и неизменяемые пакеты результатов. Технические попытки, пилот и подтверждающая серия маркируются раздельно.

Утверждённая схема веток из постановки: `main`, `platform/metal`, `platform/cuda`. Создание и публикация этих веток остаются участникам.
